ROSの説明資料

ROSを使った勉強の進め方

ROSを使うにはロボット工学やシステム構築など様々な知識が必要なので、ヒントを書いておきます

1. 環境構築

  1. Dockerを推奨
  2. 環境構築でつまずかない
  3. トラブル回避が容易
  4. 環境構築例

2. 困ったとき

  1. ROS日本コミュニティを活用
  2. 公式サイト
  3. Slack招待フォーム

ROSの便利な点

  1. リアルタイムデータ交換が簡単 ← フォーカス
  2. 豊富な可視化・制御ツール ← 次回紹介

ROSのプログラム基本単位：ノード

  1. 1ノード=1プロセス
  2. 機能ごとに分割可能
  3. 柔軟なシステム構築

ノード間の通信：トピック、サービス、アクション

パラメータ管理

  1. 設定値の一元管理
  2. ROS1：パラメータサーバー
  3. ROS2：ノード別管理
  4. 動的変更が可能

ROSbag

  1. データ記録・再生フォーマット
  2. センサーデータの保存
  3. 解析・デバッグに活用
  4. rosbag record -O my_bag.bag /topic1

データの可視化

  1. PlotJugglerが便利
  2. bagファイル読み込み
  3. データのグラフ化
  4. CSVエクスポート

データの再生

  1. rosbag play my_bag.bag
  2. 全データ再生は困難
  3. 記録時に抜け落ちるデータ有
  4. 完全再現は現実的でない

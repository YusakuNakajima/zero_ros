# ロボットの遠隔操作 ~バイラテラル制御と模倣学習~

ロボットの遠隔操作の方法、バイラテラル制御の種類と加速度制御型バイラテラル（ABC）、遠隔操作データを使った模倣学習を扱うスライド。ROS のバージョンに依存しない内容なので `index.html` 1 本のみ（ランディングページでは通し番号 12、応用編「遠隔操作」）。

## スライド構成

1. **タイトル**：ロボットの遠隔操作 / バイラテラル制御と模倣学習
2. **参考資料**：境野 2022（日本ロボット学会誌 40(9)）、土岐 openarm 勉強会資料、JSME 機械工学事典「バイラテラル制御」、Lawrence 1993、Yokokohji & Yoshikawa 1994、Suzuki & Ohnishi 2013、ALOHA / ACT（RSS 2023）
3. **遠隔操作とは**（縦 2 枚）
   - なぜ遠隔操作？：危険・遠隔地 → 人手不足 → 学習データ集め
   - ロボットを操作する方法：ゲームパッド・キーボード / VR コントローラ / リーダ・フォロワ（ALOHA、GELLO）/ バイラテラル制御 を「何を送る・直感的・力が返る」で比較
4. **バイラテラル制御とは**（縦 2 枚）
   - 位置を送り力を返す図、ユニラテラルとの違い、理想（x_L = x_F, f_L + f_F = 0）
   - 同型（関節空間で 1 対 1、重さ・摩擦がそろう）と異種（作業空間、IK・スケーリング、重さが違い干渉しやすい、ALOHA は異スケール）
5. **バイラテラル制御の種類**：位置対称型・力逆送型・力帰還型・4ch 型の表（リーダ側・フォロワ側・力センサ・軽さ・安定性）、操作性と再現性、模倣学習には 4ch 型が好ましい（境野 2022）
6. **加速度制御型バイラテラル（ABC）**（縦 2 枚）
   - 準備：外乱オブザーバ（DOB）の図。外乱を推定して打ち消し加速度制御に、反力推定オブザーバで力センサレス
   - ABC：和のモード＝力制御（f_L + f_F → 0）、差のモード＝位置制御（x_L − x_F → 0）。大西公平先生（慶應）のグループ。制御周波数の目安（500 Hz 心もとない / 1 kHz うれしい / 10 kHz 神：土岐）
7. **遠隔操作のデータで学習する**（縦 2 枚）
   - 遠隔操作のデータ＝学習データ（記録 → 人とリーダを AI に置き換え。ALOHA / ACT、Bi-ACT）
   - コラム：同じロボット 2 台でバイラテ × 学習（境野先生・筑波大学）。従来は応答値を指令にして制御の遅れでずれる／バイラテではリーダの応答（＝指令）を予測し、教示時と同じ制御系・同じ遅れなので人が補ったスキルごと再現。制約：同じロボット・同じ制御系を 2 台

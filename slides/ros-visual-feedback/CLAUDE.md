# ビジョンフィードバック制御 ~画像が合うまで動き続ける~

応用編「Visionベース」の 3 本目（ランディングページでは通し番号 9、物体検出の次）。構成と体裁（参考資料 → なぜ必要か（アプリ）→ 種類 → ハードウェアと制御の注意点 → 方式ごとの章（とは・数式・調整）→ ROS 2 実装 → 活用事例 → コラム章 → ありがとう）は力制御のスライド（`../ros-arm-force-control/index_ros2.html`）に合わせている。数式スライドは力制御と同じく「式 → 左に変数（入力/出力）・右に計算の 4 ステップ」。ROS 2 前提で `index.html` 1 本のみ。

## 主張

- うれしいことは 2 つ：① 目として使える（毎回違う置き方・動く物）② **精度が上がる**（画像が合うまで動き続けるので、キャリブレーションやロボットのモデルの誤差がフィードバックの中で吸収され、結果として精度が出る）。② がいちばんおいしい点（著者の考え）。
- コラム：「絶対位置精度」はデカルト的（自分を基準にした絶対の XYZ）な見方。作業では相手に対する相対位置だけが大事（アリストテレス的）。川村貞夫「相対位置誤差でロボットを動かす」（チトセロボティクス 技術コラム、https://chitose-robotics.com/column ）を出典明記で引用。

## スライド構成

1. **タイトル**
2. **参考資料**：Chaumette & Hutchinson 2006（記号はこれに合わせる）、Hutchinson/Hager/Corke 1996、Corke の教科書、川村コラム。前提としてカメラ・物体検出のスライドへリンク
3. **なぜビジョンフィードバックか**（縦 3 枚）：アプリ `interactive_app/look_and_move_vs_feedback.html`／うれしいことは 2 つ／なぜ誤差が消えるのか（見てから動く＝誤差が足し算、見ながら動く＝画像の中のずれだけが基準の図）
4. **種類**（縦 3 枚）：見てから動く vs 見ながら動くの表／IBVS と PBVS の図／Eye-in-Hand と Eye-to-Hand
5. **ハードウェアと制御の注意点**（章タイトル＋縦 3 枚）：フレームレートと遅れ（遅れ＋高ゲインで振動の図、30〜60 fps、1000 fps 級の高速ビジョン）／見えなくなると止まる（視野外・隠れ・検出の揺れ、物体検出スライドへ）／指令は速度で（カメラ 30〜60 Hz とロボット 125 Hz〜1 kHz をつなぐ、MoveIt Servo）
6. **画像ベース（IBVS）**（章タイトル＋縦 4 枚）：IBVS とは（Teach by Showing）／数式 v_c = −λ L̂⁺ (s − s*)／相互作用行列 L（点の 2×6 行列、3 点以上、Z* 固定でよい）／ゲイン λ の調整
7. **位置ベース（PBVS）**（章タイトル＋縦 3 枚）：PBVS とは／数式 v_c = −λ t, ω_c = −λ θu／IBVS と PBVS の使い分けの表
8. **ROS 2 での実装**（章タイトル＋縦 2 枚）：構成図（カメラ → 特徴検出 → サーボノード（自作）→ MoveIt Servo → ros2_control）、ViSP／サーボノードの Python コード（L を s*, Z* で固定、速度の上限、TwistStamped を MoveIt Servo へ）
9. **活用事例**（章タイトル＋縦 2 枚）：チトセロボティクス「クルーボ」（キャリブレーション不要、0.02 mm は同社発表値と明記）／よくある使われ方の表（ピン挿入・コネクタ・追従・実験器具）
10. **コラム「絶対位置精度」は本当に必要か？**（章タイトル＋縦 5 枚）：デカルトの見方／アリストテレスの見方（リンゴの図）／キャリブレーションは理想を追う作業／相対位置で動かす（いずれも川村コラムの引用＋解説）／筆者の考え
11. **まとめ**、**ありがとうございました**

## インタラクティブアプリ

`look_and_move_vs_feedback.html`：真上の固定カメラ画像の中で 2 リンクアームの手先を部品の穴に合わせる。ずれ（リンク長・カメラ位置・カメラ角度の誤差）をスライダーで与え、「見てから動く」（1 回撮影 → 思っているカメラで座標換算 → 思っているリンク長で IK）と「見ながら動く」（毎周期、画像の中の手先と穴のずれ → 思っているモデルのヤコビ行列で少しずつ動く）を比べる。初期値（1.5%・5 mm・1.5°）で前者は約 4.5 mm ずれ、後者は 0.05 mm 未満に収束。部品はドラッグで動かせる。iframe 埋め込み時は見出しと注記を隠す。

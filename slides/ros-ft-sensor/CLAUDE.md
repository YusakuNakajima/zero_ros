# フォーストルクセンサの使い方

このスライドは、ROSでのフォーストルクセンサの活用に関する実践的なガイドです。センサの基本概念から実装まで、フォース制御に必要な知識を学習します。約15枚のスライドで構成されています。

## 対象者
- ROS中級者〜上級者
- フォース制御を実装したい開発者
- ロボット学習に力覚情報を活用したい研究者
- 精密作業ロボットの制御者

## 主要な学習ポイント

### フォーストルクセンサの基礎
- **6軸測定**: 3軸力（Fx, Fy, Fz）と3軸トルク（Tx, Ty, Tz）の同時計測
- **取り付け位置**: ロボットアーム先端（Eye-in-Hand）またはベース（Eye-to-Hand）
- **測定原理**: ひずみゲージによる微小変形の検出
- **精度特性**: 高分解能・低ノイズでの力覚情報取得

### 主要な用途と応用
- **フォース制御**: 位置制御では実現困難な繊細な作業
- **コンプライアンス制御**: 環境との相互作用を考慮した適応制御
- **力分散制御**: 粉体粉砕での乳鉢中心推定などの特殊応用
- **ロボット学習**: 位置情報だけでは不十分な触覚情報の付加
- **安全監視**: 衝突検出・過度な力の抑制

### ROSでの実装技術
- **データ読み出し**: geometry_msgs/WrenchStampedでの標準化
- **Leptrinoセンサ**: 日本国内で広く使われる高性能センサ
- **パッケージ導入**: 3ステップでの簡単セットアップ（clone, rosdep, build）
- **デバイス接続**: USB接続での簡単セットアップ（/dev/ttyACM*, /dev/ttyUSB*）
- **デバイス管理**: /dev/serial/by-idでの固有パス識別
- **データ確認**: rostopic echo, rqt_plotでのリアルタイム監視
- **リアルタイム処理**: USB/Ethernet接続での高速データ取得
- **キャリブレーション**: センサの零点調整・感度補正

### ノイズ除去技術
- **ホワイトノイズ対策**: 無負荷状態でのデータ収集とFFT解析
- **フィルタ設計**: scipy.signal.butterでの低域通過フィルタ
- **移動平均**: リアルタイム処理でのノイズ平滑化
- **外れ値除去**: 異常値の検出と除去アルゴリズム
- **周波数解析**: FFTによる周波数ドメインでの処理

### 座標変換の実装
- **TFシステム**: ROSの標準座標変換フレームワーク
- **フォース変換**: 回転行列による直接的な座標変換
- **トルク変換**: 回転行列 + 位置ベクトル外積による補正
- **tf2_geometry**: 幾何学的変換の高レベルライブラリ
- **リアルタイム変換**: 動的な座標系間でのデータ変換

## 技術仕様と実装詳細

### センサインターフェース
- **通信方式**: USB 3.0/Ethernet接続でのリアルタイム通信
- **データ形式**: geometry_msgs/WrenchStampedでの標準化
- **サンプリング周波数**: 通常1kHz以上での高速データ取得
- **分解能**: 力：mN単位、トルク：μNm単位での高精度測定

### 実用的な応用例
- **粉体粉砕**: XY軸力の平均値による乳鉢中心位置推定
- **研磨作業**: 表面法線方向への均一な力印加
- **組み立て作業**: 挿入時の力フィードバック制御
- **触覚学習**: 人間の巧緻動作の力覚パターン学習

### データ処理パイプライン
- **生データ取得**: センサからの生の6軸データ
- **ノイズ除去**: フィルタリングによる信号品質向上
- **座標変換**: センサ座標系からロボット座標系への変換
- **制御システム統合**: 力制御ループへの信号入力

## パフォーマンス考慮事項

### リアルタイム性
- **低レイテンシ**: 制御ループでの遅延最小化
- **高周波数**: 1kHz以上でのデータ更新
- **同期処理**: 位置制御との時刻同期
- **優先度設定**: リアルタイムスケジューリング

### ノイズ対策
- **機械的振動**: 取り付け剛性の確保
- **電気的ノイズ**: シールド配線・接地対策
- **温度ドリフト**: 環境温度補償
- **信号処理**: デジタルフィルタでのノイズ除去

## 推奨学習フロー

4. **安全機能**: 過負荷検出・緊急停止

### 実践段階
1. **フォース制御**: PID制御での力制御実装
2. **コンプライアンス制御**: 環境適応制御
3. **学習システム**: 力覚情報を含む学習データ構築
4. **複合制御**: 位置・力の協調制御システム

## 注意点とベストプラクティス

### センサ選択
- **測定範囲**: 作業に必要な力・トルク範囲の適切な選択
- **分解能**: 制御精度に応じた感度選択
- **接続方式**: USB vs Ethernet の用途別選択
- **ロバスト性**: 産業環境での耐久性考慮

### 実装上の注意
- **キャリブレーション**: 定期的な零点調整・感度確認
- **座標系統一**: センサ・ロボット・作業座標系の一貫性
- **エラー処理**: センサ故障・通信エラーへの対応
- **安全設定**: 力制限値の適切な設定

### システム統合
- **制御ループ**: 位置制御との協調・干渉回避
- **時刻同期**: 各センサデータの時刻整合性
- **計算負荷**: リアルタイム性を損なわない処理設計
- **データロギング**: デバッグ・解析用のデータ記録

## 関連技術・ツール

### 開発支援ツール
- **RViz**: リアルタイム力ベクトル可視化

- **rqt_plot**: 簡易的なデータプロット機能

### 数値計算ライブラリ
- **SciPy**: signal処理・フィルタ設計

- **tf2_geometry**: 幾何学的変換の高レベル処理

### 制御フレームワーク
- **ros_control**: 標準的な制御フレームワーク

- **force_torque_sensor_controller**: 専用コントローラ
- **joint_trajectory_controller**: 位置制御との協調

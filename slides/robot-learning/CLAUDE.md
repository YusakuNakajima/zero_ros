# 学習ベースのロボット制御 ~模倣学習・強化学習・基盤モデル~

センサベース制御・遠隔操作の発展として、学習ベースのロボット制御の全体像をまとめるスライド。ROS のバージョンに依存しないので `index.html` 1 本のみ（ランディングページでは通し番号 11）。動画は YouTube（赤リンク）とプロジェクトページ（青リンク）を各スライドに埋め込み、最後に一覧を置く。リンクは oEmbed / HTTP で存在を確認済み（2026-10-13）。

## スライド構成

1. **タイトル**
2. **古典制御と学習制御**（縦 2 枚）：古典制御の得意（繰り返し・力・フィードバック・保証）と苦手（毎回違う物・柔らかい物・暗黙知・長い手順）／学習制御の 2 本柱（模倣学習・強化学習の図）
3. **模倣学習**（縦 5 枚）：データと動かし方の図（① 時刻ごとの「画像＋関節角 → 次の関節角」の組、② 方策を学習、③ カメラ → 方策 → 位置制御 → ロボットのループ）／種類の表（BC・DAgger・IRL・GAIL）／BC の 2 つの壁（誤差の積み重なり・多峰性の図）／ACT（ALOHA、10 分のデモで 80〜90%、Mobile ALOHA の動画）／Diffusion Policy（ノイズ除去の図、15 タスクで平均 46.9% 向上、日本語解説動画）
4. **強化学習**（縦 3 枚）：データと動かし方の図（① シミュレータで並列に試行、② 方策 ⇄ シミュレータの行動・状態・報酬と報酬の例、③ 方策を固定して PD 制御経由で実機へ）／種類の表（PPO・SAC・Dreamer・CQL）／Sim-to-Real（ドメインランダム化、OpenAI Dactyl・ルービックキューブ・DeXtreme）
5. **最近の流れ（時系列）**：強化学習・模倣学習・基盤モデルの 3 段タイムライン（2016〜2026）
6. **データをどう集めるか**：遠隔操作・手持ち（UMI）・シミュレーション・人の動画、Open X-Embodiment、LeRobot
7. **基盤モデル：VLA**（縦 2 枚）：VLA の図と RT-2・OpenVLA・π0/π0.5・Gemini Robotics・GR00T N1／コラム「実験の自動化から見た VLA」（筆者の考え：再現性は古典制御、ばらつきは学習。VLA に全面賛成ではないが重要な流れ）
8. **展望**：古典制御と学習制御の「できること・まだ難しい・役割分担」の表（上に学習・下に古典制御）
9. **動画・プロジェクトページ集**
10. **まとめ**

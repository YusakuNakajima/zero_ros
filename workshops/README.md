# Workshops Directory

このディレクトリには、ロボット勉強会の開催案内スライドが含まれています。

## ディレクトリ構造

```
workshops/
├── README.md                           # このファイル
└── YYYY-MM-DD_workshop-name/          # 各勉強会のディレクトリ
    ├── index.html                      # 開催案内スライド
    └── assets/                         # 必要に応じて画像等
```

## 新しい勉強会の追加方法

1. **ディレクトリを作成**
   ```bash
   mkdir workshops/YYYY-MM-DD_workshop-name
   ```

2. **スライドファイルを作成**
   - `index.html` - 開催案内スライド
   - 既存のスライドをテンプレートとして使用

3. **必要に応じてアセットを追加**
   - `assets/` ディレクトリに画像等を配置

## スライドテンプレートの要素

開催案内スライドには以下の要素を含めることを推奨：

- **タイトルスライド**: 勉強会名、日時、講師名
- **概要**: 開催期間、時間、形式、対象者
- **各日のプログラム**: 内容、参加リンク
- **準備・前提知識**: 推奨環境、必要な知識
- **講師紹介**: 連絡先含む
- **注意事項**: 録画禁止等のルール
- **スライド資料へのリンク**: メインのスライド集へのリンク
- **終了スライド**: 挨拶とお問い合わせ先

# ロボットアーム入門解説資料 制作ガイド

ロボットアーム入門（ゼロからのROS入門）に関する解説資料（スライド、フローチャート、可視化アプリ）の制作手順をまとめたものです。

-----

## \#\# 🛠️ 開発環境と事前準備

作業を始める前に、開発環境のセットアップと、Googleスライドからのデータ移行を行います。

### \#\#\# 開発環境

開発は**Visual Studio Code**で行います。以下の拡張機能を導入すると、効率的に作業を進められます。

  * **Draw.io Integration**: VS Code上でdraw.ioのファイルを直接編集できます。
  * **Live Server**: ローカルサーバーを立ち上げ、`reveal.js`スライドのプレビューをリアルタイムで確認できます。

### \#\#\# Googleスライドからのデータ移行

`reveal.js`でスライドを生成するため、Googleスライドから画像とテキストを以下の手順でエクスポートします。

1.  **画像ファイルの準備**:
    Googleスライドを一度PowerPoint形式（`.pptx`）でエクスポートします。その後、ダウンロードした`.pptx`ファイルの拡張子を`.zip`に変更して解凍し、画像ファイル（`media`フォルダなど）を抽出します。

2.  **テキストファイルの準備**:
    Googleスライドの「ファイル」メニューから「形式を指定してダウンロード」→「プレーンテキスト（.txt）」を選択し、スライドの全テキストを書き出します。

-----

## \#\# 1. スライド作成の手順

事前準備で用意したデータをもとに、`reveal.js`形式のスライドを作成・修正します。

### \#\#\# 1.1. スライドの生成プロンプト

**Claude Code**を使い、準備した画像とテキストから`reveal.js`の雛形を生成します。

```prompt
"origin_slides"ディレクトリに格納されている画像とテキストファイル（.txt）を基に、reveal.js形式のプレゼンテーションを新規作成してください。

# 要件
- 画像は"media"ディレクトリにコピーし、スライド内から参照してください。
- スライドの文章は、提供されたテキストファイルの内容を基に構成してください。
```

### \#\#\# 1.2. スライド内容の修正プロンプト

生成されたスライドを、以下の指示に基づき修正します。

```prompt
既存のreveal.jsスライドを、以下の指示通りに修正してください。

スライドを修正して、最後にアップデートにあわせてclaude.mdも更新

番号はスライドの番号を表していて、階層構造がある場合は番号をネストしてあります

空白は修正点なし

アニメーションを全て除いて

背景画像以外は基本的に画像は左、文字は右です

# 具体的な変更点
1.
2. 画像を変更、上はイラストで学ぶロボット工学、下は実践ロボット制御
3. スライドを追加、このスライドの目的、メーカーが用意した制御では難しいロボットアームの軌道制御をするための資料になります
```

## \#\# 2. フローチャート作成の手順

既存のフローチャート画像を、`draw.io`で編集可能なXMLファイルに変換します。

**プロンプト例 (Gemini 1.5 Pro):**

```prompt
あなたはdraw.ioという描画ツールで読み込めるXMLファイルを作成することはできますか？

添付の画面イメージの画像をdraw.ioファイルで編集可能な形にしたいと考えています。

画面イメージを読み込んで、draw.ioファイルのXMLを出力してください。
```

## \#\# 3. 可視化アプリ作成の手順

ジンバルロック現象を直感的に理解するためのWebアプリケーションを作成します。

**プロンプト例 (Gemini 1.5 Pro):**

```prompt
オイラー角によるジンバルロックの課題とクオータニオンがジンバルロックを回避できることを視覚的にわかりやすく理解できるアプリを作って
```

> **💡プロンプトのコツ**
> 「視覚的に分かりやすく」のような抽象的な依頼だけでなく、「ジンバルロック」「クォータニオン」といった**専門用語を使い、何をどう表現したいかを具体的に指定する**ことが重要です。
